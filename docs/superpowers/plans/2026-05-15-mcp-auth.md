# MCP Server Bearer Token Auth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add opt-in Bearer token authentication to the MCP server's HTTP transport — if no token is configured, the server behaves exactly as today.

**Architecture:** A new `src/mcp-auth.ts` module handles token storage (`mcp-auth.json` in configDir) and provides a `checkBearerToken` HTTP guard. Three `mcp token` subcommands manage the token. `startMcpServer` loads the token once at startup and calls the guard at the top of the HTTP request handler before any method/path branching.

**Tech Stack:** Node.js `node:crypto`, `node:fs/promises`, `node:http` (IncomingMessage, ServerResponse), oclif Command, mocha + chai

```ts
import {existsSync} from 'node:fs'
import {mkdir, readFile, unlink, writeFile} from 'node:fs/promises'
import type {IncomingMessage, ServerResponse} from 'node:http'
import {join} from 'node:path'

function authFilePath(configDir: string): string {
  return join(configDir, 'mcp-auth.json')
}

export async function readMcpAuth(configDir: string): Promise<string | null> {
  try {
    const content = await readFile(authFilePath(configDir), 'utf8')
    return (JSON.parse(content) as {token: string}).token
  } catch {
    return null
  }
}

export async function writeMcpAuth(configDir: string, token: string): Promise<void> {
  if (!existsSync(configDir)) {
    await mkdir(configDir, {recursive: true})
  }

  await writeFile(authFilePath(configDir), JSON.stringify({token}, null, 2), 'utf8')
}

export async function deleteMcpAuth(configDir: string): Promise<void> {
  try {
    await unlink(authFilePath(configDir))
  } catch {
    // file absent — nothing to do
  }
}

export function checkBearerToken(req: IncomingMessage, res: ServerResponse, token: string): boolean {
  if (req.headers['authorization'] === `Bearer ${token}`) return true
  res.writeHead(401, {'WWW-Authenticate': 'Bearer'})
  res.end('Unauthorized')
  return false
}
```
