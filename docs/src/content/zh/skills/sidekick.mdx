# `sidekick` 技能

`sidekick` 技能指示 Claude 在使用任何 MCP 服务器、shell 命令或外部 API 之前，先运行 `sdkck search`。它会被自动触发——你无需手动调用它。

## MCP 服务器 vs. 技能

[MCP 服务器](/mcp)和本技能都能将你的智能体连接到 Sidekick——请二选一，不要同时使用。

|         | MCP 服务器                                                 | `sidekick` 技能                               |
| ------- | ---------------------------------------------------------- | ---------------------------------------------- |
| **方式** | 将 sdkck 暴露为 MCP 工具（`search_tools`、`run_command`） | 指示智能体通过 shell 运行 sdkck CLI |

## 安装

### Claude Code

```bash
claude plugin marketplace add hesedcasa/sdkck
claude plugin install sidekick@cli
```

### 其他编码工具

使用 [skills CLI](https://github.com/vercel-labs/skills) 安装，以便与 Cursor、Codex、OpenCode 以及[另外 40 多种智能体](https://github.com/vercel-labs/skills#supported-agents)配合使用：

```bash
npx skills add hesedcasa/sdkck --skill sidekick
```

全局安装（在所有项目中可用）：

```bash
npx skills add hesedcasa/sdkck --skill sidekick -g
```

指定某个特定的智能体：

```bash
npx skills add hesedcasa/sdkck --skill sidekick -a cursor
npx skills add hesedcasa/sdkck --skill sidekick -a codex
npx skills add hesedcasa/sdkck --skill sidekick -a opencode
```

## 它的作用

每当 Claude 即将调用会触及外部系统的工具时，该技能就会介入，先执行一个发现步骤：

```bash
sdkck search "jira issue create"
```

如果 Sidekick 有匹配的命令，Claude 就会改用它。只有当搜索没有返回任何相关匹配时，Claude 才会回退到其他工具。

## 覆盖的系统

| 用户提到……                          | Sidekick 搜索……                      |
| --------------------------------------- | ------------------------------------------- |
| Jira、工单、issue、epic、sprint       | `sdkck search "jira <keyword>"`             |
| Sentry、错误、事件、异常         | `sdkck search "sentry <keyword>"`           |
| SQL、数据库、查询、表、schema           | `sdkck search "mysql"` / `"postgres"`       |
| Supabase、认证用户、行级          | `sdkck search "supabase <keyword>"`         |
| Confluence、wiki、页面、空间           | `sdkck search "confluence <keyword>"`       |
| Bitbucket、PR、仓库、分支             | `sdkck search "bitbucket <keyword>"`        |
| 任何已导入的 API / Postman 集合   | `sdkck search "<api name or operation>"`    |
| 其他任何触及外部系统的操作 | 无论如何都搜索——空结果意味着回退 |

## 核心工作流程

```bash
sdkck search "create jira issue"   # 1. 发现
sdkck jira issue create --help     # 2. 检查
sdkck jira issue create ...        # 3. 运行
```

## 示例

```
Agent: I need to check recent Sentry errors and create a Jira ticket.

> sdkck search "sentry errors"          # Discovers the right command
> sdkck sentry issues list --recent     # Gets the data
> sdkck jira issue create ...           # Acts on it
```
