# Claude Code

First-class integration with Claude Code through the plugin marketplace and MCP server.

## Install as a plugin

```bash
claude plugin marketplace add hesedcasa/sdkck
claude plugin install sidekick@sidekick
```

## Configure as MCP server

Add to `.mcp.json` in your project:

```json
{
  "mcpServers": {
    "sdkck": {
      "command": "sdkck",
      "args": ["mcp", "start"]
    }
  }
}
```

This gives Claude Code access to two MCP tools:

- **`search`** — Discover available commands
- **`run_command`** — Execute any Sidekick command

## Add to CLAUDE.md

Add instructions so Claude Code knows to use Sidekick:

```
Before any tool call run `sdkck commands | grep <keywords>` to find the available tools in sdkck,
e.g.: `sdkck commands | grep -i "jira|issue"`
```

## Example workflows

### Triage Sentry errors to Jira

```
> sdkck search "sentry errors"
> sdkck sentry issues list --recent
> sdkck jira issue create --project MYPROJ --summary "Fix: [error details]"
```

### Query database and create Confluence page

```
> sdkck search "database query"
> sdkck psql query "SELECT count(*) FROM users WHERE created_at > now() - interval '7 days'"
> sdkck conni page create --title "Weekly User Report" --body "..."
```

### Import API and test endpoints

```
> sdkck openapi import https://api.example.com/openapi.json --name myapi
> sdkck myapi listUsers
> sdkck myapi getUser --param id=42
```
