# Commands

Sidekick provides built-in commands and dynamically registers commands from imported OpenAPI specs.

## Built-in commands

| Command                | Description                   |
| ---------------------- | ----------------------------- |
| `sdkck commands`       | List all sdkck commands.      |
| `sdkck help [COMMAND]` | Display help for sdkck.       |
| `sdkck search QUERY`   | Search for available commands |
| `sdkck version`        | Show version info             |

## API commands

| Command                           | Description                                                                     |
| --------------------------------- | ------------------------------------------------------------------------------- |
| `sdkck api import SOURCE`         | Import an OpenAPI spec, Postman collection, or GraphQL schema                   |
| `sdkck api list [NAME]`           | List imported API specs and their available operations                          |
| `sdkck api call NAME OPERATIONID` | Call an imported API operation                                                  |
| `sdkck api auth add API`          | Add an auth profile for an imported API                                         |
| `sdkck api auth update API`       | Update an auth profile for an imported API                                      |
| `sdkck api auth delete API`       | Delete an auth profile for an imported API                                      |
| `sdkck api auth list API`         | List auth profiles for an imported API                                          |
| `sdkck api auth profile API`      | Get or set the default auth profile for an imported API                         |
| `sdkck api config NAME`           | Update configuration for an imported API spec                                   |
| `sdkck api remove NAME`           | Remove an imported API spec                                                     |

## Permission commands

| Command                             | Description                                                     |
| ----------------------------------- | --------------------------------------------------------------- |
| `sdkck permission allow PATTERN`    | Allow a command pattern in the permission list                  |
| `sdkck permission check COMMAND`    | Check whether a command is allowed and which rule decides it    |
| `sdkck permission disallow PATTERN` | Disallow a command pattern in the permission list               |
| `sdkck permission export FILE`      | Export the permission configuration to a JSON file              |
| `sdkck permission import FILE`      | Import the permission configuration from a JSON file            |
| `sdkck permission list`             | List all rules in the permission list                           |
| `sdkck permission remove PATTERN`   | Remove a rule from the permission list                          |
| `sdkck permission reset`            | Reset all permission rules                                      |

## Plugin commands

| Command                            | Description                                         |
| ---------------------------------- | --------------------------------------------------- |
| `sdkck plugins`                    | List installed plugins.                             |
| `sdkck plugins add PLUGIN`         | Installs a plugin into sdkck.                       |
| `sdkck plugins:inspect PLUGIN...`  | Displays installation properties of a plugin.       |
| `sdkck plugins install PLUGIN`     | Installs a plugin into sdkck.                       |
| `sdkck plugins link PATH`          | Links a plugin into the CLI for development.        |
| `sdkck plugins remove [PLUGIN]`    | Removes a plugin from the CLI.                      |
| `sdkck plugins reset`              | Remove all user-installed and linked plugins.       |
| `sdkck plugins uninstall [PLUGIN]` | Removes a plugin from the CLI.                      |
| `sdkck plugins unlink [PLUGIN]`    | Removes a plugin from the CLI.                      |
| `sdkck plugins update`             | Update installed plugins.                           |

## Synonyms commands

The `search` command matches command synonyms; export and import them as JSON:

| Command                        | Description                                            |
| ------------------------------ | ------------------------------------------------------ |
| `sdkck synonyms export [FILE]` | Export the stored synonyms to a JSON file or stdout    |
| `sdkck synonyms import FILE`   | Import synonyms from a JSON file                       |

## MCP commands

| Command                     | Description                                                |
| --------------------------- | ---------------------------------------------------------- |
| `sdkck mcp start`           | Start the MCP server (stdio or Streamable HTTP transport)  |
| `sdkck mcp token generate`  | Create a Bearer token enforced by the HTTP transport       |
| `sdkck mcp token show`      | Display the current MCP HTTP token                         |
| `sdkck mcp token delete`    | Remove the MCP HTTP token (disabling auth)                 |
| `sdkck mcp client add`      | Register an external MCP server's tools as CLI commands    |

The MCP commands come from the JIT plugins `@hesed/mcp-server` and `@hesed/mcp-client`, which auto-install on first use — that is why they do not appear in `sdkck commands` output before installation. See [MCP Server](/mcp) and [MCP Client](/mcp-client).

## Dynamic commands

When you import an OpenAPI spec, every operation becomes a command under the spec name:

```bash
# After importing a spec named "petstore"
sdkck petstore listPets
sdkck petstore getPetById --param petId=42
sdkck petstore createPet --body name=Fido
```

These dynamic commands appear in `sdkck help` and `sdkck commands` just like built-in commands.

## Getting help

```bash
sdkck --help              # General help
sdkck api --help          # Topic help
sdkck api import --help   # Command-specific help
```
