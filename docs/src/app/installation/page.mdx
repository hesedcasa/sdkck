# Installation

Install Sidekick globally with npm:

```bash
npm install -g sdkck
```

## Requirements

- **Node.js** v22 or later (>=22.0.0)

## Verify installation

```bash
sdkck version
# sdkck/0.36.4 linux-x64 node-v22.x.x
```

## Optional dependencies

### OpenAI API key (for semantic search)

Set the `OPENAI_API_KEY` environment variable to enable AI-powered semantic search. When unset, search falls back to fuzzy matching.

```bash
export OPENAI_API_KEY=sk-...
sdkck search "create Jira issue"
```

## Updating

```bash
npm update -g sdkck

# Update all plugins
sdkck plugins update
```

## Install plugin

```bash
# Install an official plugin
sdkck plugins install @hesed/jira

# Install from GitHub url
sdkck plugins install https://github.com/someuser/someplugin
```
