# Installation

Install Sidekick globally with npm:

```bash
npm install -g sdkck
```

## Requirements

- **Node.js** v22 or later

## Verify installation

```bash
sdkck version
# sdkck/0.37.0 linux-x64 node-v24.x.x
```

## Optional dependencies

### OpenAI API key (for semantic search)

Set the `OPENAI_API_KEY` environment variable to enable AI-powered semantic search. When unset, search falls back to fuzzy matching.

```bash
export OPENAI_API_KEY=sk-...
sdkck search "create Jira issue"
```

## Updating

```bash
npm update -g sdkck

# Update all plugins
sdkck plugins update
```

## Install plugin

```bash
sdkck plugins install @hesed/jira

# Install from GitHub url
sdkck plugins install https://github.com/someuser/someplugin
```

## Install skill

Agent skills are not sdkck plugins: they install instructions from GitHub into your coding agent, so they do not replace the `sdkck` executable installed above. Install with the [skills CLI](https://github.com/vercel-labs/skills) to use with Cursor, Codex, OpenCode, and [40+ other agents](https://github.com/vercel-labs/skills#supported-agents):

```bash
npx skills add hesedcasa/sdkck --skill sidekick
```

Install globally (available across all projects):

```bash
npx skills add hesedcasa/sdkck --skill sidekick -g
```

Target a specific agent:

```bash
npx skills add hesedcasa/sdkck --skill sidekick -a cursor
npx skills add hesedcasa/sdkck --skill sidekick -a codex
npx skills add hesedcasa/sdkck --skill sidekick -a opencode
```

The `extract-api` skill installs the same way:

```bash
npx skills add hesedcasa/sdkck --skill extract-api
```

For multi-page documentation sites, `extract-api` spawns the `web-crawler` agent, defined at `plugins/api/agents/web-crawler.md`, which the skills CLI does not install. The [Claude Code plugin](/skills/extract-api#claude-code) remains the complete installation route for that skill.

See the [sidekick](/skills/sidekick) and [extract-api](/skills/extract-api) skill pages for full context.
