# Sidekick

为 AI 智能体打造的最佳伴侣工具。用一个 CLI 搜索、连接并操控你技术栈中的每一个工具。零上下文窗口膨胀，最大化生产力。

```bash
# Install Sidekick globally
npm install -g sdkck

# Update Sidekick
npm update -g sdkck

# Update all plugins
sdkck plugins update

# Search for commands
sdkck search "create Jira issue"
```

## 功能特性

- **API 转命令** — 导入任意 OpenAPI 规范或 Postman Collection，每一个端点都会变成一条 CLI 命令
- **语义搜索** — 通过模糊匹配或 AI 驱动的匹配找到合适的命令
- **插件系统** — 官方插件在首次使用时自动安装
- **权限系统** — 细粒度控制智能体可以执行哪些命令
- **MCP 服务器** — 将整个插件生态暴露为一个 MCP 服务器

## 兼容工具

Claude Code、Cursor、GitHub Copilot、OpenAI Codex、Google Gemini、opencode，以及任何能够运行 shell 命令的智能体。

## 示例

```bash
# Show all available commands
sdkck commands

# Show help for specific topic
sdkck help jira

# Show help for specific command
sdkck help jira issue create

# Import an OpenAPI spec
sdkck api import https://petstore3.swagger.io/api/v3/openapi.json --name petstore
sdkck petstore listPets # execute command directly

# Show output in TOON format for token saving
sdkck jira issue get PROJ-123 --toon
```

## 架构

基于 [oclif](https://oclif.io) 构建的 Node.js CLI，采用插件化架构：

3. **插件系统** — 官方插件（`@hesed/*`）被声明为 JIT 插件，在首次使用时自动安装。
4. **MCP 服务器** — 基于 [Model Context Protocol SDK](https://modelcontextprotocol.io/docs/sdk) 构建，通过 stdio 暴露所有命令以实现无缝集成。
5. **权限系统** — 一份基于 glob 的允许列表，控制哪些命令可见且可执行。

## 支持平台

以 npm 包的形式发布。可在安装了 **Node.js v18+** 的 macOS、Linux 和 Windows 上运行。
